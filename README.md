# Site de teste — Tenda de Zé Cigano

Este repositório é o ambiente de teste dos módulos antes de qualquer versão final.

## Padrão de arquivos

- `index.html`: versão visual publicada no ambiente de teste.
- `site versão V16.txt`: cópia de referência da interface escolhida.
- `codigo.gs versao V04 M01.txt`: backend preparado para o Módulo 01 e para a planilha fictícia de teste.

Os arquivos `.txt` registram as versões entregues e não devem ser colados por cima de outros arquivos sem conferir o nome e a versão.

## Estado do Módulo 01

- Layout responsivo da página inicial: versão V16.
- Conteúdo da página inicial configurável por planilha: backend V04 preparado.
- Conexão do backend com esta interface: pendente de instalação e validação no Apps Script de teste.
- Login, páginas internas e permissões: etapas futuras; os botões atuais da prévia ainda exibem mensagens de demonstração.

## Regra de publicação

Mudanças são avaliadas primeiro neste repositório de teste. O repositório `Tendadezecigano` permanece apenas com a mensagem temporária de construção até a revisão e aprovação do site final.
